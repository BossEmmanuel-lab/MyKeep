# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in MyKeep, please do **not** open a public issue.

Instead, please privately report it by:
1. Contacting the maintainer directly via GitHub Security Advisories, or
2. Reaching out via email to `bossemmanuel3106@gmail.com` with:
   - A clear description of the vulnerability.
   - Detailed steps to reproduce or proof-of-concept.
   - Any suggested mitigations.

We will review, acknowledge, and resolve security issues promptly.
